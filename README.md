# Нейрогимнастика 12

Тестовый лендинг практического онлайн-курса Сергея Брызгалина для проекта «Вселенная нейрохакинга».

Страница — статический сайт: `index.html`, `styles.css` и изображения в `assets/`. Сборка и установка зависимостей не нужны. Для просмотра откройте `index.html` в браузере или запустите локальный сервер в этой папке:

```sh
python3 -m http.server 8000
```

Старт 1 декабря 2026 года указан предварительно. Стоимость, условия доступа и ссылка на запись ещё уточняются; кнопка обращения открывает почтовое приложение.
